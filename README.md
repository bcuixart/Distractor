# Distractor
An application made to enhance your computer experience by introducing random annoying distractions.

## Configuration file
This application uses a configuration file to customize the behavior of the distractions.
You can specify the amount of time between distractions and the applications to be used.
An example configuration file can found in 'config.txt'. You can change the file used by launching the application with the file path as an argument. For example:
```.\distractor.exe my_beautiful_configuration_file.abc```

## Example applications:
### 1. DVD Logo
A simple application that displays a bouncing DVD logo on your screen. Clicking on the logo will make it disappear.
